# Marketing & Sales Decks

Module drafted 2026-10-09 from research dossier (Track B, Dossier 3). Purpose: give an AI agent the canonical structure, design conventions, and failure modes for the two sales-adjacent deck types, so the deck it builds is a closing tool or a demand-gen asset, not a company brochure.

## 1. Two genres, one folder

| | Marketing deck | Sales deck |
|---|---|---|
| Purpose | Demand generation, awareness | Deal-closing conversation tool |
| Depth | High-level, persuasive | Deeper, consultative |
| Structure | Fixed, linear narrative | Reconfigurable mid-meeting around the buyer |
| Visuals | Minimal, aspirational | Product-led (show the product) |
| Proof | Traction, brand momentum | Case studies, ROI, testimonials |
| Tone | Aspirational | Consultative |

- [ ] You named which genre you are building in the first planning line (a demand-gen deck and a closing deck are different artifacts with different arcs).
- [ ] The deck is built for the BUYER, not for the company's ego (benefits-first, buyer-specific — Entrepreneur India 2025).

## 2. Canonical 12-slide sales arc

1. Cover
2. Problem (the buyer's pain)
3. Solution
4. Key features (3 hero features, not the whole catalog)
5. How it works (3 steps)
6. Social proof
7. Expected results / ROI
8. Pricing
9. Why us vs alternatives
10. Onboarding
11. Team / about
12. Next steps / CTA

Enterprise variant (15–20 slides): add cost-of-inaction, security, implementation timeline, and an appendix.

- [ ] The arc is present in order; no slide is skipped silently (if pricing is omitted, say why).
- [ ] Features are capped at 3 heroes; the full feature list lives in the appendix or not at all.
- [ ] There is exactly one unambiguous next step (demo, pilot, call).

## 3. The Zuora archetype (Raskin — the most-cited sales-deck teardown)

1. Open with an undeniable world-shift, NOT the problem. Problem-first puts prospects on the defensive.
2. Raise the stakes of the shift.
3. Present the product as "Magic Gifts" that get the buyer to the "Promised Land."
4. Frame all evidence inside that context.

- [ ] The opening names a world-shift the prospect cannot deny (not a complaint about their pain).
- [ ] The product is introduced as the means to the promised outcome, not as a list of capabilities.

## 4. "Sales deck" is NOT "marketing plan deck"

The internal marketing planning deck (objectives → audience → journey → positioning → competition → funnel → channels → calendar → measurement) is a different artifact: it has **no pricing and no CTA**, and it is not shown to buyers. One research-track gallery template labeled "marketing" turned out to be exactly this planning deck — do not treat it as a sales-deck reference.

- [ ] If the brief asks for a sales deck, it contains pricing (or a pricing frame) and a CTA; if it asks for a marketing plan deck, it contains neither.

## 5. Objection handling is a structural feature

Include a risk/objection slide ("Questions We Can Resolve") — the canonical arc does not name one, but real-world sales templates treat it as a structural feature.

- [ ] At least one slide pre-empts the top 3 buyer objections instead of leaving them for Q&A.

## 6. Design conventions

- [ ] One idea per slide; 6–8 lines of text max ("billboard clarity").
- [ ] Visual hierarchy holds: headline = the point, subhead = the context, proof = the evidence.
- [ ] 3-second test: a stranger gets the slide's point in 3 seconds (if not, cut).
- [ ] Product-led visuals: if you say it, show it (screenshot, demo frame, diagram).
- [ ] Proof blocks are present: logo bars, testimonials, before/after frames.
- [ ] Value prop is stated in the formula: "We help [audience] achieve [result] through [method]."
- [ ] Palette is restrained: 2–3 brand colors, one icon style throughout.
- [ ] Dual-mode: a light version for the live meeting plus a detailed appendix (or speaker notes) for the send-ahead read-alone version.
- [ ] Metrics are headlined as takeaways, e.g. "Increased conversion 32% in 60 days" — never a bare number.

## 7. Common mistakes (fail the build if any survive)

- [ ] No "slideument" (a document crammed into slides).
- [ ] No feature-dumping (the full catalog on slide 4).
- [ ] No company-first opening (history, offices, mission on slide 2).
- [ ] Clear visual hierarchy on every slide (no text walls at uniform size).
- [ ] Proof is real and attributed (no weak/absent proof).
- [ ] Not one-size-fits-all (at least the problem/proof slides are buyer-specific).
- [ ] Objections are handled, not dodged.
- [ ] No logo soup (a wall of logos with no context).
- [ ] No overdesign (decoration that competes with the message).

## 8. India notes

- [ ] WhatsApp is a first-class Indian sales channel (Deasra 2026): WhatsApp/email pitches must be short, scannable, and end with one clear next step. If the deck will be summarized for WhatsApp, plan the 5-line scannable version alongside it.
- [ ] Anti-pattern reference: "Sanjeevani decks" (TOI 2026: 50 slides for a 15-minute slot, "in the interest of time, let's skip this slide", inconsistent font sizes). Treat as editorial/anecdotal, NOT measured fact. No quantitative India-vs-global deck norms were found.
- [ ] Entrepreneur India (2025): benefits-first, customize per buyer, before/after framing — the dossier's sourced India-specific sales-design advice.

## 9. Field notes (Track C, clearly labeled)

- Honest gap: zero real company sales decks were obtainable as .pptx (all login-walled or PDF).
- Gallery templates (flattened) tracked the canonical arc closely — the best canonical fit in the study — with assertion-dominant titles ("From Friction to Forward Motion", "Proof in Practice") and ~20–40 words/slide.
