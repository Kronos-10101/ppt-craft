# Case study presentation — reference module

**Purpose:** recommend a course of action on a business problem, defended before a jury. In India, case competitions double as recruitment pipelines (dossier dated 2026-10-09).

## Canonical structure (CBS toolkit, 5-part)

### Part 1 — Executive summary / set the stage (1–2 slides)

- [ ] SCQA framing: Situation → Complication → Question → Answer.
- [ ] **Recommendation stated UP FRONT** on slide 1 or 2 — never held as a reveal.
- [ ] A busy judge reading only this part must know what you propose and why.

### Part 2 — Key insights driving to the recommendation (2–4 slides)

- [ ] Each insight is a mini-argument: evidence first, then what it proves.
- [ ] Insights ladder up: every one of them must point at the recommendation.
- [ ] Cut any finding that is interesting but does not move the verdict.

### Part 3 — Solution detail, "the body" (2–5 slides)

- [ ] The recommendation broken into operable pieces: what changes, for whom, how.
- [ ] Wireframes, 4Ps, operating-model detail — concrete, not slogans.

### Part 4 — Impact, risk, implementation (3–4 slides)

- [ ] Impact quantified: revenue, cost, share, or whatever the prompt's scoreboard is.
- [ ] Risks named with mitigations — an unmitigated risk is a verdict against you.
- [ ] Implementation: owners, timeline, milestones. A recommendation with no path is a wish.

### Part 5 — Summary + call to action (1 slide)

- [ ] Restate the recommendation and make the ask of the jury explicit.

### Indian winner's arc (alternate sequencing, same spine)

- [ ] Problem Statement + scope → Research (fieldwork evidence) → Top-3 Insights → Ideas (often 4Ps, wireframes) → Feasibility — technical / financial / operational, flagged as **"critical"** → Finance & Timeline.
- [ ] The feasibility section is where Indian juries probe hardest; treat it as load-bearing, not filler.

## Budget

- [ ] **10–15 slides, 10–20 min + 5–10 min Q&A.** Confirm the comp's cap before building: ITC Interrobang caps at 10 slides; L'Oréal Brandstorm caps at 10 slides, 16:9 PDF; Mahindra War Room campus rounds ran 20 min + 10 Q&A.
- [ ] 1–2 min per slide maximum. Slower than that means too much text or no story.
- [ ] Many Indian comps filter on the **written deck before any live pitch**: the deck must be self-explanatory, closer to a read-alone document deck than to talk cues.

## Design conventions

- [ ] **Action titles:** each slide title is a complete-sentence takeaway, 7±2 words (e.g. "Acquisition would be dilutive in year one").
- [ ] **Title-only read-through test:** reading only the titles in sequence must reconstruct the full argument. Fails = restructure.
- [ ] **One slide = one message.** Two arguments on one slide means neither lands.
- [ ] **Sourced exhibits:** one chart or table per slide; each carries a source line (plus units/date where relevant).
- [ ] **Pyramid / SCQA flow:** the insight sits above its supporting data; data never precedes the claim it supports.
- [ ] **"So what?" per slide:** every exhibit must end in an implication, not a description.
- [ ] **Appendix discipline:** everything the jury might ask goes in a tight appendix — pre-empt the skeptic, not a 60-slide dump.
- [ ] **2–3 colors**, applied consistently; color marks the insight, never decorates.
- [ ] Number audit: every figure on every slide is checked against the appendix source before delivery.

## Common mistakes

- [ ] Buried meaning: topic labels ("Market Analysis") instead of assertion titles.
- [ ] Text-heavy slides: juries skim; they do not read paragraphs.
- [ ] Skipping the feasibility / finance spine — analysis with no "can it work and what does it cost".
- [ ] Rigid framework application: 5 Forces or SWOT presented as the answer instead of used as a tool.
- [ ] Losing the prompt: a sharp recommendation to the wrong question scores zero.
- [ ] Unsupported exhibits: charts with no sources, or with no clear takeaway.
- [ ] Presentation-day failures: unreadable mini-diagrams, no rehearsed Q&A, demo that was never tested.

## Delivery checklist

- [ ] Rehearsed Q&A: every appendix slide has a speaker who can walk to it without hunting.
- [ ] Time-boxed: finishes inside the slot with Q&A time protected.
- [ ] Self-explanatory: a reader without the speaker still gets the recommendation and the case for it.

## India appendix (sourced)

- [ ] **HUL L.I.M.E.** (top-prestige B-school comp): one-pager-per-category template with hard word limits of **30 / 75 / 100 words**; roughly a dozen top B-schools invited.
- [ ] **ITC Interrobang:** 10-slide cap, **"no pre-determined structure"**; originality/creativity is the highest-weighted criterion; winners get a PPI + ₹1,00,000.
- [ ] **L'Oréal Brandstorm** (global, running since 1992): 10 slides max, 16:9, PDF submission; 5+5 world finals format; winners recruited.
- [ ] **Mahindra War Room** (2009–~2024) → rebranded as the **Mahindra Rise Challenge** (Forbes India).
- [ ] **Structural India-vs-global differences:** sponsor-proprietary formats replace Minto structures; creativity can outrank analysis rigor; the written deck often filters before any live pitch, so decks must be self-explanatory.

## FIELD NOTES (Track C — observed, not prescribed)

Empirical parse of 6 real decks (GCCH M&A submissions). Deviations from canon below are what real submissions look like, not what the skill recommends:

- Submissions ran **38–106 slides**, with 25–40% appendix and 7–12 bibliography slides.
- Assertion headlines dominated, often two-line (topic + assertion, e.g. "An acquisition of Vestas would be dilutive to Siemens").
- Median **180–307 words/slide** — very dense, far above talk-deck norms.
- **Zero native PPTX charts**: all visuals were pasted images (552 images in one deck). Zero speaker notes in any deck.
- Recommendation stated TWICE (executive summary + conclusion); financials presented BEFORE the recommendation as evidence; no standalone implementation section in 3 of 4 decks.
- "Alternatives" meant an alternate acquisition target with a full mini-valuation; industry analysis ran 8–12 slides.
- A Table of Abbreviations appeared in all decks — absent from the canon.
